# EventHub

EventHub is a web application for managing and discovering events. Users can browse events, register for events, manage tickets, and receive notifications, while administrators can manage events, users, registrations, and view analytics.

## Technologies

The project is built using:

- React.js – Frontend
- JavaScript – Frontend logic
- Python – Backend
- Flask – REST API
- HTML & CSS – Structure and styling
- SQLite – Database
- Git & GitHub – Version control

The frontend communicates with the Python backend through REST API endpoints.
